Avant de commencer

Ce qu'il faut prévoir, et le lien entre les TP et les chapitres du cours.

Matériel et comptes

  • TP1 : Ubuntu 24.04 (machine ou VM), 8 Go de RAM recommandés.
  • TP2 : VirtualBox et un poste de 16 Go de RAM recommandés (4 VM de 2 Go).
  • TP3 : un compte AWS. Les instances sont facturées à l'heure : arrêtez-les après chaque séance.
  • TP4 : Docker Engine et Docker Compose V2, 8 Go de RAM disponibles pour Docker.
