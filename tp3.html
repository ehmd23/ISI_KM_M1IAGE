Déployer le cluster Hadoop dans le cloud AWS (EC2)

Le même cluster de 4 nœuds que dans le TP2, mais sur des instances EC2 louées à l'heure — et le même job MapReduce pour comparer.

Master 1 — IAGEAnnée 2026-2027Hadoop 3.4.3Java 21Python 3Ubuntu 24.04 LTSAWS EC2Version 2.0 · Octobre 2026

Objectif

1 master + 3 workers sur EC2, HDFS et YARN, puis le job « CA par ville » en Java et en Python.

Lien avec le cours

Chapitre 3 — Hadoop sur site ou plateforme cloud ; chapitre 1 — CAPEX et OPEX.

Enjeu métier (IAGE)

Mesurer ce que change le cloud : un cluster disponible en minutes, payé à l'usage… et une facture à surveiller.

Sommaire

    Étape 0 : Lancement des instances EC2 et Security Group

    Coût : les instances t3.medium ne font pas partie de l’offre gratuite et sont facturées à l’heure. Arrêtez-les (Stop) à la fin de chaque séance et supprimez-les (Terminate) à la fin du TP. C’est l’illustration concrète du modèle OPEX vu au chapitre 3 : on paie ce qu’on consomme… y compris ce qu’on oublie d’éteindre.

    1. Dans la console AWS EC2, lancez 4 instances avec les paramètres suivants :

    • AMI : Ubuntu Server 24.04 LTS
    • Type d’instance : t3.medium (2 vCPU, 4 Gio de RAM)
    • Paire de clés : votre clé .pem
    • Volume racine : 30 GiB gp3
    • Security Group : créez un groupe nommé hadoop-cluster-sg avec les règles entrantes suivantes :
    TypeProtocolePortSourceDescription
    SSHTCP22My IPConnexion SSH depuis votre poste
    All trafficAllAllSecurity group hadoop-cluster-sg (Self)Communication interne entre les nœuds
    Custom TCPTCP9870My IPNameNode Web UI
    Custom TCPTCP8088My IPYARN ResourceManager UI

    2. Après le lancement, nommez les instances : master, datanode1, datanode2, datanode3.

    Notez l’IP privée du master (exemple : 172.31.36.23).

    Étape 1 : Configuration initiale sur chaque instance

    Connectez-vous sur chaque instance en tant que ubuntu :

    ssh -i votre-cle.pem ubuntu@<Public-DNS>

    Exécutez les commandes suivantes sur chaque instance :

    sudo nano /etc/ssh/sshd_config

    Assurez-vous que ces deux lignes sont présentes et non commentées :

    PasswordAuthentication yes
PubkeyAuthentication yes
    Ubuntu 24.04 sur AWS : le fichier /etc/ssh/sshd_config.d/60-cloudimg-settings.conf contient PasswordAuthentication no et prend le dessus sur sshd_config. Mettez-y aussi PasswordAuthentication yes, sinon ssh-copy-id (étape 5) échouera. Une fois les clés copiées, repassez cette valeur à no : un serveur exposé sur Internet ne doit pas accepter les mots de passe.

    Puis redémarrez SSH :

    sudo systemctl restart ssh

    Définissez le hostname :

    sudo hostnamectl set-hostname master        # Sur master
sudo hostnamectl set-hostname datanode1     # Sur datanode1
sudo hostnamectl set-hostname datanode2     # Sur datanode2
sudo hostnamectl set-hostname datanode3     # Sur datanode3

    Configurez le fichier hosts :

    sudo nano /etc/hosts

    Ajoutez le contenu suivant (remplacez par vos IPs privées réelles) :

    172.31.36.23    master
172.31.39.208   datanode1
172.31.xx.xx    datanode2
172.31.yy.yy    datanode3
127.0.0.1       localhost

    TotalSalesByCity.java

    À créer dans src/main/java/sn/ehmd/TotalSalesByCity.java. Le mapper lit le format tabulé de purchases.txt : ville en index 2, montant en index 4.

    package sn.ehmd;

import org.apache.hadoop.conf.Configuration;
import org.apache.hadoop.fs.Path;
import org.apache.hadoop.io.DoubleWritable;
import org.apache.hadoop.io.LongWritable;
import org.apache.hadoop.io.Text;
import org.apache.hadoop.mapreduce.Job;
import org.apache.hadoop.mapreduce.Mapper;
import org.apache.hadoop.mapreduce.Reducer;
import org.apache.hadoop.mapreduce.lib.input.FileInputFormat;
import org.apache.hadoop.mapreduce.lib.output.FileOutputFormat;

import java.io.IOException;

public class TotalSalesByCity {

    public static class SalesMapper extends Mapper<LongWritable, Text, Text, DoubleWritable> {
        private final Text city = new Text();
        private final DoubleWritable amount = new DoubleWritable();

        public void map(LongWritable key, Text value, Context context) throws IOException, InterruptedException {
            String line = value.toString().trim();
            if (line.isEmpty()) return;

            String[] fields = line.split("\t");
            if (fields.length >= 5) {
                try {
                    String cityName = fields[2].trim();              // ville (index 2)
                    double saleAmount = Double.parseDouble(fields[4].trim()); // montant (index 4)

                    city.set(cityName);
                    amount.set(saleAmount);
                    context.write(city, amount);
                } catch (NumberFormatException e) {
                    System.err.println("Erreur parsing ligne: " + line);
                }
            }
        }
    }

    public static class SalesReducer extends Reducer<Text, DoubleWritable, Text, DoubleWritable> {
        private final DoubleWritable total = new DoubleWritable();

        public void reduce(Text key, Iterable<DoubleWritable> values, Context context)
                throws IOException, InterruptedException {
            double sum = 0.0;
            for (DoubleWritable val : values) {
                sum += val.get();
            }
            total.set(sum);
            context.write(key, total);
        }
    }

    public static void main(String[] args) throws Exception {
        Configuration conf = new Configuration();
        Job job = Job.getInstance(conf, "Total CA par ville");

        job.setJarByClass(TotalSalesByCity.class);
        job.setMapperClass(SalesMapper.class);
        job.setReducerClass(SalesReducer.class);

        job.setOutputKeyClass(Text.class);
        job.setOutputValueClass(DoubleWritable.class);

        FileInputFormat.addInputPath(job, new Path(args[0]));
        FileOutputFormat.setOutputPath(job, new Path(args[1]));

        System.exit(job.waitForCompletion(true) ? 0 : 1);
    }
}

    Variante Python — Hadoop Streaming

    Sur AWS, réutilisez les scripts du TP2 (src/main/python/ du dépôt) : copiez-les depuis votre poste avec scp -i votre-cle.pem *.py ubuntu@<Public-DNS>:/tmp/, puis sur le master sudo cp /tmp/*.py ~hadoop/ && sudo chown hadoop:hadoop ~hadoop/*.py.

    # Sur le master, avec Python 3 installé sur tous les nœuds
chmod +x total_sales_by_city_mapper.py total_sales_by_city_reducer.py

hdfs dfs -rm -r -f /output-ca-py

hadoop jar $HADOOP_HOME/share/hadoop/tools/lib/hadoop-streaming-*.jar \
  -files total_sales_by_city_mapper.py,total_sales_by_city_reducer.py \
  -mapper "python3 total_sales_by_city_mapper.py" \
  -reducer "python3 total_sales_by_city_reducer.py" \
  -input /input/purchases.txt \
  -output /output-ca-py

hdfs dfs -cat /output-ca-py/part-*

    Le résultat Python doit correspondre à la sortie Java (/output-ca).
